Doctor Appointment Management System
====================================

Description:
This project is a Doctor Appointment Management System that allows administrators, doctors, and patients to manage appointments efficiently.

Project Structure:
- `admin/`: Contains files for admin functionalities like managing doctors, appointments, and admin login.
- `assets/`: Contains CSS and image assets for the project.
- `database/`: Contains SQL files for setting up the database.
- `doctor/`: Contains files for doctor functionalities like managing schedules, appointments, and profiles.
- `includes/`: Contains reusable components like headers, footers, and database connection.
- `patient/`: Contains files for patient functionalities like booking appointments and managing their dashboard.
- `index.php`: The main entry point of the application.

Setup Instructions:
1. Import the `doctor_appointment.sql` file from the `database/` directory into your MySQL database.
2. Configure the database connection in `includes/db.php`.
3. Start a local server and access the application via `index.php`.
